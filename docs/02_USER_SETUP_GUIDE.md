# 2. Руководство пользователя по настройке NEXUS IPTV

1. **Добавление источника IPTV:** перейдите в раздел **«Источники IPTV»**, выберите вкладку **«Плейлист M3U / M3U8»** или **«Xtream Codes API»**, введите данные вашего легального провайдера и нажмите **«Добавить и загрузить»**. Пароли автоматически шифруются в аппаратном хранилище `AndroidKeyStore`.
2. **Телепрограмма EPG:** если ссылка `url-tvg` указана в заголовке плейлиста `#EXTM3U`, она подхватится автоматически. В разделе **«Телепрограмма»** можно скорректировать сдвиг времени (`±30 мин`), вручную привязать `EPG ID` к любому каналу и поставить напоминание (`🔔`) о начале передачи.
3. **Управление с пульта ДУ в полноэкранном эфире:**
   - `CH+` / `CH-` — мгновенное переключение каналов без выхода из полноэкранного режима;
   - `Цифры 0..9` — прямой набор номера канала;
   - `Кнопка Menu` — прозрачный боковой список каналов поверх эфира;
   - `Кнопка Info / Guide` — лента `Quick Switch` (быстрый возврат к последним каналам);
   - `Долгое нажатие OK` на канале — контекстное меню (Избранное, Блокировка PIN-кодом, Скрыть).
4. **Жесты на смартфонах и планшетах:**
   - Свайп вверх/вниз по **левой** стороне экрана — регулировка яркости;
   - Свайп вверх/вниз по **правой** стороне экрана — регулировка громкости.
