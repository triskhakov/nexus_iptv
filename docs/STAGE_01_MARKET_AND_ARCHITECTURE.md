# Этап 1. Исследование рынка и архитектурная спецификация NEXUS IPTV

1. **Потоковый парсинг O(1) по памяти**: M3U и XMLTV читаются через `BufferedReader` и `XmlPullParser` с записью в Room пакетами по 500 записей.
2. **Аппаратное разделение UI**: `:core:ui-tv` для управления исключительно пультом (D-Pad) и `:core:ui-mobile` для сенсорного управления с жестами.
3. **Smart Stream Engine**: расчёт `ChannelHealthScore` (0..100) и автоматический переход на резервный поток при обрыве соединения.
4. **Аппаратная защита секретов**: шифрование паролей в `AndroidKeyStore` (`AES-256-GCM`) и маскирование токенов в `UrlRedactor`.
